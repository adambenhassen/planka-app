A native client for Planka, the open-source kanban board. Point it at your own
self-hosted Planka 2.x server and work your boards from your phone, with every
change synced live over a websocket in both directions.

This app is not a service. There is no account to create, no backend of ours in
the middle, and nothing is collected: it talks only to the server address you
type in.

FEATURES

- Multi-account: sign in to several Planka servers and switch between them
  instantly.
- Projects and boards: browse everything you have access to, set project
  backgrounds, manage project managers.
- Kanban board: drag and drop cards across lists, filter and sort, all
  live-synced.
- Full card details: description, due dates, labels, members, checklists,
  attachments, comments and the activity feed.
- Complete editing: create, rename, edit and delete cards, lists, labels,
  checklists, tasks and comments.
- Move, duplicate and restore: move cards across boards and projects, duplicate
  cards, browse the archive and trash and restore from them.
- Profile and admin: edit your profile and avatar; administrators can manage
  server users.
- Notifications: realtime unread badge, mark read and mark all read.
- Realtime everywhere: changes made in the web UI appear here at once, and the
  other way round.

REQUIREMENTS

A self-hosted Planka 2.x server that this device can reach. If you do not run
one yet, Planka is free and open source: https://github.com/plankanban/planka

The app is open source under the MIT license. Source, issue tracker and
releases: https://github.com/adambenhassen/planka-app
